# 任务 02：最小化 Windows guest（module-b，P0）

请先阅读 handoff/README.md，重点配合 01 完成真实内核原型。

## 目标与范围

实现已有 guest provider 的真实后端：配置校验、启动、就绪握手、执行程序、运行结果、取消、停止与异常恢复。先选择公开支持实际 guest 需求的虚拟化产品或 API，并记录选择依据与性能约束。

先交付一个可连接本机已配置 guest 的可运行后端，再评估精简 guest 与自建 VMM。guest 内只安装正常授权的系统和必要服务，保持内核、签名与完整性验证链路。

游戏与反作弊的 CPU 执行状态属于同一 guest。宿主和 guest 的路径不能直接互用；实现明确的文件映射、参数传递和 guest agent 协议。不得通过拼接任意 shell 字符串传参。

## 接口与状态

与 05 固定：配置状态、VM 状态、运行会话标识、guest 架构、可执行文件映射、退出码、超时、取消及可读错误。与 01 固定驱动探针需要的通信与日志接口。

## 交付与验收

普通测试程序可启动并返回真实退出码；未安装后端、无 guest、错误架构、文件不可见、guest 未就绪、取消和 VM 崩溃均有明确状态。

提供系统占用和游戏负载的基线数据；精简必须测量并记录具体变化。不要仅因就绪握手成功就把受保护游戏标成受支持。

## 文件归属

guest provider、配置、会话、guest agent 及通信协议实现。共享接口交给 05；不修改反作弊厂商组件。
