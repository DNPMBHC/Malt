# 运行环境、游戏启动与完整安装包整合

日期：2026-11-26  
维护：@DNPMBHC

本阶段处理游戏启动链路、macOS 系统服务授权和应用载荷整合。交接文档作为实现参考；应用外的系统授权与环境准备仍由用户明确操作。

## 当前实现

- 安装器请求与安装完成分开记录。选择真实游戏入口后才能加入可快速启动的条目。
- 容器冷启动等待来宾工具；交互任务须返回所选路径和有效进程标识，失败、取消和超时不会误报成功。
- 控制引擎登记显式打开的实例，拒绝标识冲突；自动化权限拒绝有稳定错误和系统设置指引。
- 原生网络通过 macOS 的后台服务机制申请、刷新和撤销；服务入口就绪不代表容器已经配置或实际联网。
- 网络配置仅作用于完全关机、无保存态且受管理的可玩实例；写入前核验引擎与磁盘状态，支持私有备份、回读校验与恢复，拒绝配置漂移。
- 完整安装包内嵌控制引擎、独立 Python 标准库、管理脚本、网络服务和中英首次运行指南，校验所有受管载荷的哈希与动态依赖。
- 对外分发门禁独立检查 Developer ID、Team ID、安全时间戳、公证和严格签名；ad-hoc 包只作为本地测试制品。

## 首次运行流程

1. 将完整应用放入应用程序目录。
2. 按所选引擎准备运行环境：合法 Windows ARM64 实例及来宾工具，或受支持的 Wine 运行时。
3. 导入或选择运行环境，再保存游戏在该环境中的真实执行路径。
4. 如需原生网络，在运行环境页主动申请授权，按系统提示批准，再刷新状态；容器停止后才应用网络配置。
5. 先验证普通游戏启动，再分别验证原生联网、安装器交互、管理员提示与取消流程。

本包不包含 Windows 镜像或许可证、Wine 核心运行库、游戏或游戏许可证。开发工作区和开发者机器上的 Python 不应成为运行前提。

## 验收证据

最终计数与安装包结果以 evidence/ 中最新的 swift-tests.json、python-gates.json、swiftlint-all.json、package-build-status.json、package-manifest.json 和 dmg-final-verification.json 为准。历史失败保留为诊断材料，不能作为本次成功证据。

主应用存活、解释器启动、资源完整性和合成测试，不等同于真实游戏或另一台 Mac 已验收。真实来宾、在线连接、系统批准交互和跨机验证须分别记录。

## 仍需真实环境验收

- Windows 来宾内的安装器、桌面交互、UAC、游戏主程序与取消。
- 系统自动化授权、后台服务批准，以及容器启用网络后的实际连接。
- 使用有效 Developer ID 与公证的完整应用，在另一台支持的 Mac 上从零完成首次配置。

本阶段不提交或推送，不替换现有用户数据，不修改游戏或反作弊文件。
