# 任务 06：厂商支持与兼容证据（module-f，P0）

请先阅读 handoff/README.md，与 01 同步展开。

## 研究范围

分别研究 VALORANT、League of Legends Windows 客户端、THE FINALS 的当前反作弊体系、驱动架构、OS/CPU 要求、VM 政策和公开合作接口。区分全球版与不同发行区域，以及 macOS 原生客户端和 Windows 客户端。

优先使用厂商、系统和虚拟化平台的一手资料。每个结论记录页面标题、公开 URL、访问日期、适用产品/版本和证据摘录；没有证据时明确未知。不要从某款其他游戏能在某个 VM 运行推定目标游戏可用。

## 交付

供程序消费的中性兼容数据格式、可审查的证据矩阵、每条状态的来源与更新时间、对 01/02 的工程输入。

区分发行方允许、驱动能加载、游戏能启动、能进入实际受保护会话四类结论；任一变化都不能自动提升其余状态。

## 验收与边界

每款目标都有独立证据和明确未解决项。公共资料缺口可以列为厂商沟通问题，但未经用户明确授权不联系厂商或发送信息。

不编辑 UI 或共享模型；新增字段交给 05。任何需要真实账号的验证交由集成任务按用户已有授权执行。
