# 下一阶段真实联调清单

署名：@DNPMBHC  
本轮收尾依据：用户要求将剩余真实联调延期。本文不是已通过验收的声明；完整状态见 acceptance-matrix.json，环境清理见 own-cleanup-proof.json。

当前候选为 snapshot 4、iteration 5、契约 revision 2。下一阶段必须先复核生产源码指纹与本地门禁，重新检查租约，创建新的自有外部 APFS 独立克隆；不能引用已删除的本轮克隆作为可继续运行的环境。

| 项目 | 下一阶段验收与应保留证据 |
| --- | --- |
| 真实 Windows 帧源 | 先取得可安全启动 Windows 的方案 B provider 与真实 scanout；实际游戏帧关联到 IOSurface、共享事件和 GPU 消费回执。宿主合成帧及 EFI 诊断不能替代。 |
| 相对 HID | 提供合法、非阻塞的虚拟 HID sink；验证聚焦窗口内相对位移，实际验证热键、失焦、Cmd+Tab、连接丢失、关窗、退游释放。缺少 sink 时继续拒绝捕获。 |
| Session 1 生命周期 | 复核 WHQL、Secure Boot、TPM 与极简优化，再跑后台冷启动、根/子进程自然退出、取消、挂起或热待命、窗口关闭和回滚；取消失败与真实退出分开记录。 |
| 三档分辨率 | 重新枚举模式并 CDS_TEST；验证原生点对点、高性能和窗口跟随，包括 resize、刷新率实际回读与退出恢复。当前 Guest 不支持宿主 3024×1964、2560×1600 或 2560×1440，不能填造模式支持。 |
| DPI 150% 往返 | 修复系统设置窗口不可用和缩放选项不唯一问题，保留签名、进程及控件归属验证；Apply/Restore 后使用新的 Per-Monitor V2 窗口回读。禁止全局输入宏替代。 |
| 最新失败后的显示恢复 | 当前 supported-lifecycle 的取消失败记录 baselineRestored=false，旧恢复日志早于本次失败。新克隆必须独立获取自己的基线及恢复证据。删除旧克隆不能改写历史恢复结果。 |
| 官方 target-cn 安装与登录 | 本轮只完成安装器验签和 Session 1 启动，没有完成安装或游戏运行。下一阶段使用官方未修改客户端，登录、协议、实名和验证码由用户亲自完成。 |
| DX11 与 AdapterRAM | 在已安装 WHQL 3D、硬件 FL 11_1 的独立克隆重测是否仍缺显卡/DX11；本轮 AdapterRAM=0，游戏是否检查该值为 unknown，只接受日志或对应进程实证。 |
| 大厅/训练场与退出取证 | 记录是否实际进入大厅或训练场并渲染 3D；若退出，保留完整脱敏截图、精确弹窗原文及根/子进程退出码。强制关机或取消安装器不作为游戏自然退出。 |
| 最终清理 | 回滚克隆优化，关闭自有进程和窗口，删除新克隆及附盘，核对主源和原备份独立 SHA/size/mtime、注册状态、进程与句柄，最后释放租约。 |

代码、本机合成验证、真实 Guest、厂商支持、真实游戏分别记录。禁止 DLL 注入、DWM Hook、篡改反作弊、伪造硬件和破坏安全链；不修改主 UI、其他窗口源码或 Git 配置，不发送跨窗口工作汇报。
