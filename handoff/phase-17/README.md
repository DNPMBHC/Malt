# 自动配置与游戏入口闭环

日期：2026-11-26  
维护：@DNPMBHC

目标是让用户拖入合法游戏安装器后，由应用处理可自动完成的环境配置、安装进度和后续快速启动。交接材料中的历史任务书仅用于理解进展，不自动成为本轮执行指令。

## 已核对的历史成果

- 第 11 阶段记录了国服 ACE 路线的 25.33 分钟教学、大厅、靶场流程，其中靶场 9.01 分钟；两个 ARM64 CORE 驱动运行，154 次 HTTP 200 心跳。受保护匹配仍未验证，厂商 VM 支持未知。
- 第 14 阶段记录了两轮真实靶场，共 36,201 帧；1920×1200 全低与全高的等效均帧分别为 60.57、54.50 FPS。独立记录采集于上海时间 2026-11-26 00:28:19。
- 第 9 阶段的 63 分钟是创角界面运行，不能写成 63 分钟匹配。第 15 阶段的部分高分辨率指标来自自有 probe，不能写成真实游戏性能。
- 第 14 阶段真实游戏纠正后的帧数限制默认值为 120；不采用原始 JSON 中仍残留的离屏 FPSLimit=0 建议。

上述均是历史单机证据。本轮没有重跑游戏，不能把它们扩大为当前安装版本、所有反作弊、跨机或匹配对局的成功。

## 本轮审计发现

1. 统一启动器原先只写宿主 installer 状态，来宾信号留在独立会话目录，未桥接到宿主窗口。历史靶场回归使用过另一种窗口模式。
2. 安装器运行回执已实现，但安装后仍需手工登记真实程序；安装成功、程序启动、反作弊就绪与在线可玩必须分别表示。
3. 第 15 阶段的 TCP/UDP 用户态代理仍是独立实验，当前应用没有打包、选择或管理该代理。不能显示为已经自动回落。
4. 原生网络注册和系统设置指引已实现，但获准后长期等待 socket 时缺少诊断期限。
5. 当前环境准备仍以合法 Windows 实例与来宾工具为前提，没有从零自动安装 Windows 的完成证据。

## 本轮实现范围

- 新增候选入口扫描与明确确认后的后端登记接口，保留 launcher 参数与工作目录并核验游戏库落盘；旧条目可继续读取。
- 已接通私有窗口会话绑定与来宾信号桥接；只有所选 exe 自身的真实前台证明可触发游戏窗口，退出、失联、取消和过期会话恢复紧凑状态。普通 launcher 派生进程尚未关联。
- 已新增原生服务 15 秒就绪诊断期限、重新授权后的计时重置和恢复后真实状态读取；系统批准与真实联网仍需单独验收。
- 不覆盖并行前端改动，不启动或修改真实虚拟机、游戏、反作弊或系统服务，不提交或推送。

## 尚未达成的产品目标

- 新 Mac 从零自动部署合法 Windows、来宾工具及完整游戏环境。
- 前端扫描候选、用户确认入口与后端核验结果的完整接线。
- 用户态网络代理随包发布并由应用管理；当前仍保留既有网络选择与批准流程。
- 官方 launcher 派生游戏子进程的可靠归属与前台联动。
- 受保护匹配、当前包真实游戏、管理员批准后的联网，以及第二台 Mac 验收。
- 有效 Developer ID、嵌套签名与公证的正式异机发行。

## 证据位置

历史真实游戏证据分别见第 11、14 阶段的真实运行报告；第 16 阶段的包验收仍是该阶段快照。本阶段已在 evidence/ 记录本次新增测试、构建与制品，不能覆盖历史验收。Swift 416 项（10 跳过、0 失败）、Python 142 项、strict lint 与实际 DMG 搬迁检查均通过；完整边界见 verification.md。当前源码与测试、制品快照一致。
